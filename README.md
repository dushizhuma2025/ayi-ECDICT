# 阿一开源英语字典 (阿一的开源英语词典)

基于离线英汉词典数据库（ECDICT）开发的单词一览与多维检索系统。本工具为阿一开发**[词友会](https://cyh.ayi001.xyz/)**的副产品。

## 项目简介

**阿一的开源英语词典** 是基于 ECDICT（自由英汉词典数据库）开发的离线单词一览与多维检索系统。
- **数据层**：启动时自动将 `ecdict.csv` 转存并创建 SQLite 本地数据库 `ecdict.db`，同时针对 `collins`、`oxford`、`tag`、`bnc`、`frq` 字段建立快速查询索引。
- **后端层**：纯 Python 零依赖架构。利用 Python 内置的 `http.server` 托管静态页面并提供 RESTful 查询接口。
- **前端层**：使用 Vanilla HTML5/CSS3/JS 搭建单页面 Web 应用（SPA），采用 Glassmorphism 暗黑毛玻璃风格与响应式表格。

本词典数据库根据各类考试大纲和语料库词频收录数十万条各类单词的英文和中文释义，并按照各类考试大纲和词频进行多维标注。

## 单词标注

数据库中每个单词均标注了以下信息，以帮助用户了解单词的重要程度：
- **考试大纲词汇**：传统考试大纲词汇标注，包括中考（zk）、高考（gk）、四级（cet4）、六级（cet6）、考研（ky）、托福（toefl）、雅思（ielts）、GRE（gre）等大纲词汇。
- **牛津 3000 核心词汇**：标注是否属于牛津核心常用词汇。
- **柯林斯星级**：包含 1 星至 5 星的常用词级标注。
- **双语料库词频**：
  - **BNC (英国国家语料库) 词频顺序**：基于英国国家语料库统计的历史与传统词频。
  - **COCA (当代美语语料库) 词频顺序**：更偏向当代美语使用频率的实时词频。
- **动词时态与词形变化**：标注了动词的过去式、过去分词、现在分词、第三人称现在时等派生变化。

## 数据格式

本字典采用 CSV 文件存储所有词条数据，用 UTF-8 进行编码。

| 字段 | 解释 |
|---|---|
| word | 单词名称 |
| phonetic | 音标，以英语音标为主（展示时自动剔除首尾中括号） |
| definition | 单词释义（英文），每行一个释义 |
| translation | 单词释义（中文），每行一个释义（支持智能词性补全） |
| pos | 词语位置/词性，用 "/" 分割不同词性 |
| collins | 柯林斯星级 |
| oxford | 是否是牛津三千核心词汇 |
| tag | 字符串标签：zk/中考，gk/高考，cet4/四级 等，空格分割 |
| bnc | 英国国家语料库词频顺序 |
| frq | 当代语料库词频顺序 |
| exchange | 时态复数等变换，使用 "/" 分割不同项目 |

## 词形变化 (Exchange)

`Exchange` 字段记录了名词复数、动词时态、形容词比较级/最高级等变换规则，格式如下：
```text
类型1:变换单词1/类型2:变换单词2
```
例如 `perceive` 的 exchange 字段为：
```text
d:perceived/p:perceived/3:perceives/i:perceiving
```
具体类型符号映射关系如下：

| 类型 | 说明 |
|---|---|
| p | 过去式（did） |
| d | 过去分词（done） |
| i | 现在分词（doing） |
| 3 | 第三人称单数（does） |
| r | 形容词比较级（-er） |
| t | 形容词最高级（-est） |
| s | 名词复数形式 |
| 0 | Lemma 原型（如 perceived 的 Lemma 是 perceive） |
| 1 | Lemma 的变换形式 |

## 编程接口与核心类

代码 `stardict.py` 支持对词典数据进行操作，提供了以下三个核心类：

| 类名 | 说明 |
|---|---|
| DictCsv | 用于读写 ecdict.csv 数据格式文件 |
| StarDict | 用来读写 SQLite 词典数据文件（数据字段和 API 接口与 CSV 相同） |
| DictMySQL | MySQL 版本的数据文件读写接口 |

主要公共接口：
- `query`：查询单词（支持行号 ID 或单词字符串搜索）
- `match`：前缀与相似单词模糊匹配
- `query_batch`：批量查询
- `count`：返回词条总数
- `commit`：提交更改

## 快速启动服务

1. 本地确保已安装 Python 3 环境。
2. 运行后端服务：
   ```bash
   python server.py
   ```
3. 服务会自动检测 `ecdict.csv`，在同级目录生成高效的本地 SQLite 数据库 `ecdict.db` 并自动创建多维索引。
4. 启动完成后，会在后台运行并自动打开浏览器访问本地页面：
   [http://localhost:8000](http://localhost:8000)
